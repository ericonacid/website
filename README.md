# ERIC ON ACID

A responsive, single-page information site for the ERIC meme-token experiment. Built with plain HTML, CSS and JavaScript; no framework, analytics, external font requests or runtime API.

## Site structure

Home, About, How it works, Rewards, and Transparency. Risks and FAQ are included within Transparency. The WORMS ON ACID creative universe is linked as a separate project; its stories and content are not duplicated here.

## Verification status

Supply, decimals, launch status, mint address, trading destination, creator holdings and wallet details remain pending verification. Do not replace those labels with estimates. Holder Rewards are conditional on activity, eligibility, vault balances and Pump.fun programme rules; distributions are not guaranteed.

## Local preview

Open `index.html` in a browser or serve this directory with any static file server.
